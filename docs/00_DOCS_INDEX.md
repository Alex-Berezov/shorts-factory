# AI Shorts Factory Project Docs

_Last updated: 2026-09-05_

This folder is the living project documentation for the multilingual YouTube Shorts experiment and the internal AI content-intelligence application.

## Files

- `00_STATUS.md` — **START HERE.** Generated project dashboard: current epic, tasks in progress, what to take next, per-epic progress, full task table. Regenerated by `node scripts/tasks.mjs`; do not edit by hand.
- `tasks/tasks.json` — single source of truth for task statuses (121 tasks E0–E13). Mutate only via `scripts/tasks.mjs`.
- `90_WORKLOG.md` — chronological work journal, appended automatically on `done`/`block`.
- `60_HARNESS.md` — how the autonomous agent team works (RU): roles, one-task cycle, locks, gates, models, rollback.
- `61_HOW_TO_WORK.md` — owner cheat sheet (RU): `/auto`, what stays with the owner, stop conditions, prerequisites per epic.
- `DECISIONS.md` — decisions taken by PM/tech lead agents instead of the owner, one row each.
- `TECH_DEBT.md` — out-of-scope findings from reviews with their outcome.
- `adr/` — architecture decision records (written on tech lead's demand).
- `01_ARCHITECTURE.md` — full product architecture, pipeline, modules, Auto Dubbing bridge, Content DNA, analytics and Experiment Engine.
- `02_PRE_DEVELOPMENT_CHECKLIST.md` — current step-by-step YouTube/API checklist with completed and pending items.
- `03_BRANDING_AND_SAAS.md` — channel naming direction, SaaS strategy and product-brand separation.
- `04_CHANNEL_BRAND_DIRECTION.md` — fictional mascot strategy and current channel-name shortlist.
- `05_CURRENT_STATUS_AND_NEXT_STEPS.md` — fastest project resume/status document; read this first after a break.
- `10_SYSTEM_DESIGN.md` — engineering system design (RU): stack, topology, queues, data model, integrations.
- `20_TZ_HIGH_LEVEL.md` — high-level spec (RU): epics E0–E13 with scope, AC, dependencies and decomposition status.
- `30_E0_TASKS.md` — epic E0 decomposition (RU): 13 tasks of 0.5–2 days, architectural decisions, acceptance table.
- `31_E1_TASKS.md` — epic E1 (Source Radar) decomposition (RU): 11 tasks, decisions on snapshots/baseline/clustering/quota, schema changes.
- `32_E2_TASKS.md` … `43_E13_TASKS.md` — decompositions of epics E2–E13 (RU), same structure: goal/AC, decisions, schema changes, 0.5–2-day tasks, acceptance table. Summary table with estimates is in `20_TZ_HIGH_LEVEL.md`.

## Current state in one paragraph

Phone verification is complete and Intermediate Features are enabled. Advanced Features are still waiting on Channel History because ID/video verification is unavailable in the current location. Crucially, YouTube Automatic Dubbing is already available and enabled, so development does not need to wait. English is the canonical/master language. While building the app, publish 4–7 real English Shorts per week, test Auto Dubbing, and continue building channel history. Once Advanced Features unlock, test manual custom Multi-Language Audio. The application can now proceed with Source Radar -> Gemini whole-video analysis -> Content DNA -> Idea Inbox -> Research -> Script -> Analytics -> Experiment Engine.
