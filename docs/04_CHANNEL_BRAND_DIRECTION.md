# Channel Brand Direction

_Last updated: 2026-09-05_

## Decision: original fictional mascot + invented global name

The reference channels define the **content format**, not our brand identity.

We will **not** copy the goose and will not build the channel around a generic existing animal archetype.

The chosen brand direction is:

- create a fully original fictional creature;
- give the creature a short invented name;
- ideally use the same word as both mascot name and channel name;
- use one global brand across languages;
- keep the name independent from a single content category;
- secure the name/handle before investing in visual identity.

---

## Channel theme

Broad viral micro-stories about unusual, funny, impressive, absurd or unexpected things happening in the world and on the internet.

Possible categories:

- strange real events;
- surprising discoveries;
- unusual human behavior;
- internet phenomena;
- technology;
- marketing/business oddities;
- animals;
- unexpected consequences;
- short real stories with a curiosity gap and payoff.

The brand must remain broad enough to move between categories without feeling inconsistent.

---

## Why a fictional creature

A fully original creature gives us a stronger long-term asset than a generic animal mascot:

- unique visual identity;
- high feed recognition;
- language-neutral;
- can become standalone IP;
- can later be animated, merchandised or reused across social platforms;
- reduces comparison with reference channels;
- does not lock us into one niche.

---

## Naming criteria

Prefer a name that:

1. Is invented rather than descriptive.
2. Is short (roughly 5–8 Latin letters).
3. Is easy to type and remember.
4. Works as a personal name for the creature.
5. Has no strong topic limitation.
6. Does not depend on English wordplay.
7. Can work internationally.
8. Looks good lowercase and uppercase.
9. Preferably has an exact clean YouTube handle.
10. Has no meaningful existing creator/product collision.

Additional observation: some generated candidates sound slightly Japanese or Italian because of vowel-heavy endings. This is acceptable, but future naming iterations should intentionally explore more phonetic variety.

## ROVUNI — rejected

`ROVUNI / @rovuni` was checked directly on YouTube and is already occupied by an existing channel with an established mascot/visual identity.

Status: **REJECTED**.

Do not use modified variants such as:

- `@rovuni_official`
- `@realrovuni`
- `@rovuniTV`
- numeric suffixes

The project is greenfield; choose a cleaner name instead.

## What to do once one name is available

1. Reserve the exact YouTube handle.
2. Keep visual branding temporary.
3. Continue technical channel setup and channel-history publishing.
4. Return later for a dedicated mascot/visual-brand sprint.

---

## Visual work intentionally postponed

Do not finalize yet:

- exact creature anatomy;
- body shape;
- face/eyes;
- color palette;
- logo;
- animation language;
- personality;
- slogan;
- intro/outro behavior;
- channel description;
- merchandise direction.

The visual system will be designed after the channel name/handle is secured and after the first technical YouTube tests are underway.
