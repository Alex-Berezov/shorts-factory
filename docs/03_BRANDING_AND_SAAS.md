# Branding, Channel Naming & SaaS Strategy

_Last updated: 2026-09-05_

## 1. SaaS decision

Potentially sell the system later as SaaS, but **do not make external SaaS the initial optimization target**.

Recommended sequence:

1. Build internal tool.
2. Run our own 90-day channel experiment.
3. Collect proprietary winner/loser data.
4. Prove that Radar + Content DNA + Experiment Engine improve decisions.
5. Only then productize the generalizable parts for external creators.

### Why this is better

The strongest asset will not be basic AI script generation. It will be the closed loop:

**trend signal -> whole-video analysis -> original production -> real analytics -> experiment learning -> better next content.**

If SaaS is launched later, consider keeping an internal advantage layer private:

- best source lists;
- proprietary scoring weights;
- internal benchmarks;
- high-performing prompt recipes;
- learned correlations from our own channels;
- best experiment playbooks.

## 2. Channel brand direction

Reference channels are inspiration for **format**, not branding.

We explicitly decided:

- do **not** copy the goose;
- do **not** use a generic existing animal as the main identity;
- build a **fully original fictional creature**;
- use a short invented global name;
- ideally the channel name and mascot name are the same word;
- visual identity/personality/slogan come after the final name/handle is secured.

The content niche remains broad:

- viral micro-stories;
- strange real events;
- surprising discoveries;
- internet phenomena;
- unusual technology/business/marketing stories;
- funny or absurd human situations;
- occasional animals/people/events;
- strong curiosity gap and payoff.

The brand must therefore **not** be locked to one topic such as facts, animals, crime or news.

---

## 3. Naming principle

Preferred channel name:

- invented;
- 5–8 Latin characters if practical;
- easy to type;
- memorable after hearing once or twice;
- usable in English, Spanish, Portuguese, French, German and beyond;
- not dependent on English wordplay;
- suitable as the personal name of a fictional creature;
- exact clean YouTube handle strongly preferred;
- no `_official`, numbers, `TV`, `real...` or similar compromise if avoidable.

A humorous observation from the naming process: several invented names naturally sounded somewhat Japanese/Italian. This is not a blocker, but future naming rounds should consciously seek more globally neutral phonetics.

## 4. ROVUNI status — rejected due collision

`ROVUNI / @rovuni` was initially a favorite, but direct YouTube checking revealed that **@rovuni is already occupied by an existing channel with its own mascot/brand identity**.

Decision:

> Do not use ROVUNI and do not use a modified handle such as `@rovuni_official`.

This validates the rule that exact availability must be checked directly inside YouTube, not inferred from general web search.

## 6. Final channel naming workflow

For each candidate:

1. Open `youtube.com/@candidate` as a quick check.
2. Search YouTube for the exact word.
3. Attempt to reserve the exact handle in channel creation/customization.
4. Reject names with meaningful existing channel/brand collisions.
5. Reject names where only ugly modified handles are available.
6. For the final 1–3 candidates, perform web/domain/trademark checks.
7. Secure the exact handle.
8. Only then design the mascot and full visual system.

---

## 7. Mascot work intentionally postponed

After the name is fixed, return to:

- creature body shape;
- eyes/face;
- proportions;
- color palette;
- personality;
- expressions;
- recurring micro-animation;
- logo/wordmark;
- avatar/banner;
- channel description;
- slogan;
- brand voice;
- how the mascot appears in Shorts without hurting retention.

Long-term goal: viewer recognizes the brand from the creature within a fraction of a second.
