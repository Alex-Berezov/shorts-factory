# /fix - правки по замечаниям

Аргумент: `$ARGUMENTS`

Два источника, третьего нет:

- `qa` - таблица последнего `## Ревью` из файла дела (`.claude/.task-current`). Ревью не было -
  скажи и остановись, `/qa` заново не гоняй: дифф не менялся.
- текст - замечание владельца как написано. Толковать шире сказанного нельзя.

## Порядок

1. **Разложить.** Одна находка - одна строка в файл дела, раздел `## Правки по замечаниям`:
   где, что не так, как чинить, кто нашёл.
2. **Отсеять.** Находку, которую считаешь неверной, не чини молча и не молчи: строка
   «не согласен, потому что …» со ссылкой на код. Спор решает `techlead` (вход по форме его
   файла); его решение исполняется.
3. **Починить** - через `worker` (`subagent_type: worker`, модель как у задачи; для правок
   в схеме/деньгах/идемпотентности - `opus`). Задание: путь к файлу дела, раздел с находками,
   «чини ровно названные места; соседнюю строку, которая тоже не очень, не трогать; каждая
   правка поведения - с тестом, который краснеет без неё».
4. **Перепроверить.** `/qa` по затронутым зонам: ревьюеры, чьи находки чинили, плюс
   `review-product`, если находка касалась DoD; из `/auto` после второго круга - полный набор.
   Затем `node .claude/hooks/gates.js`.

## Границы

Список файлов тот же, что до правок; новый файл - только если находка прямо этого требует,
и это отдельная строка в отчёте. Правка по замечанию не отменяет посадок и не даёт права
переписать соседний модуль.

Отправку делает не `/fix`: коммит - в `/auto` шаг 9 или `/done`.

## Два круга, и дальше техлид

Блокеры чинятся кругом `/fix` → `/qa`. Кругов два. Не помогло - к `techlead` с таблицей
и тем, что пробовали. Не помог и он - стоп-условие 3 из `auto.md`, а не выбор наугад.

## Ответ в чат

До восьми строк: сколько находок починено, с чем не согласен (по строке), решение техлида
(если звали), итог перепроверки одной строкой, путь к делу.
