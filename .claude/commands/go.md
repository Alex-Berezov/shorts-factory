# /go - работа по плану

1. Прочитай путь из `.claude/.task-current`, открой файл дела: должен быть раздел `## План`
   и закрытые развилки (`## Решения` или «развилок нет»). Нет плана - скажи «сначала `/task`»
   и остановись. Развилки открыты - закрой их по правилам `auto.md`, шаг 3.
2. `node scripts/tasks.mjs start <id>` (если ещё не `in_progress`).
3. Позови `worker` (`subagent_type: worker`, `model` из плана) с заданием: id, путь к файлу
   дела, «делай по разделу План». Открытые вопросы в его ответе - закрой через `pm`/`techlead`
   и позови worker снова (не больше двух кругов).
4. Остановись. Ревью и сдача - `/qa`, `/fix`, `/done`.

## Ответ в чат

До шести строк: что сделано (из итога worker одной фразой), число файлов, посадка (да/нет),
проверки исполнителя одной строкой, открытые вопросы (число или «нет»), путь к делу.
Последняя строка: «Дальше: `/qa`».
