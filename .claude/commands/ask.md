# /ask - решение PM или техлида

Вопрос: `$ARGUMENTS`

1. Классифицируй: продуктовый (что должен делать продукт, как выглядит для оператора) → `pm`;
   технический (подход, схема, зависимость, архитектура) → `techlead`; смешанный → сначала
   `pm`, потом `techlead` с ответом PM. Явное `pm`/`tl` в аргументе перебивает классификацию.
2. Подготовь вход по форме их файлов: вопрос одной строкой, два-три варианта с ценой, факты
   путями и строками (прочитай нужное сам или через `Grep`), что уже пробовали, чем откатывается.
   Вход «посмотри, как лучше» бесполезен - ответ будет таким же.
3. Позови подагента (`Task`). Ответ `Решение/Почему/Границы/Откат/Журнал` - строку `Журнал`
   допиши в таблицу `docs/DECISIONS.md` сразу; если открыт файл дела (`.claude/.task-current`) -
   и в его раздел `## Решения`. Ответ `К владельцу` - передай владельцу дословно.
4. Ответ в чат - блок решения как есть плюс одна строка «записано в docs/DECISIONS.md».
   Ничего не правь в коде: это команда про решение, не про реализацию.
