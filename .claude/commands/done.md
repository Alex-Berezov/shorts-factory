# /done - сдача задачи

Порядок жёсткий. Пропуск шага - задача не закрыта.

## 1. Ревью

`/qa` целиком. Есть блокеры - `/fix qa` → `/qa`; пока в таблице есть блокер, дальше нельзя.

## 2. Гейты

`node .claude/hooks/gates.js` без сужений, вывод в файл дела. Красный гейт - незакрытая задача,
а не «известная особенность».

## 3. Чек-лист готовности

По каждому пункту - да/нет с одной строкой доказательства в файл дела (раздел `## Сдача`).
«Нет» хотя бы в одном - задача не сдана, скажи прямо.

1. Каждый пункт «Сделать» и DoD задачи из документа эпика закрыт; `review-product` подтвердил.
2. На новое поведение есть тест, и он краснеет без правки (раздел «Посадка» файла дела).
3. Существующие тесты не подогнаны: нет `.skip`, ослабленных ассертов, изменённых ожиданий
   вместо кода.
4. Дифф в границах: каждый файл `git diff --merge-base main --name-only` объясняется задачей.
5. Ничего лишнего: временные файлы, отладка, `.env*`, `data/`, `tasks/` в диффе нет.
6. `.qa-state`: `edits` = 0, `lastQa` сегодняшний, `lastGates.code` = 0.
7. Решения pm/techlead - строками в `docs/DECISIONS.md`; ADR написан, если требовался.
8. Документы обновлены: таблица «Приёмка» эпика (если AC стал истинным), `docs/TECH_DEBT.md`
   (находки вне скоупа), README/`.env.example`, если менялись команды или переменные.
9. `TODO` без id задачи не осталось.
10. Уроки записаны (шаг 4) либо явно «уроков нет».

## 4. Уроки

Пролистай таблицу ревью. Находка, которую worker не заметил, а ревьюер нашёл, - урок (опечатка
и придирка - нет). Запиши в `.claude/qa-lessons.md` по формату файла и строку в
`.claude/qa-index.md`. Урок, целиком выражаемый регуляркой по добавленной строке, - сразу
в `standards` файла `.claude/hooks/rules.sf.json` (с пробой в `harness-selftest.js`),
а не в копилку.

## 5. Коммит

Conventional commits, id задачи в теме, на английском, один коммит на задачу:

```
git add -A
git commit -m "feat(radar): E1-03 channel sync job with shorts filter and backfill"
```

Замок `commit-gate.js` откажет без отметки `/qa` и зелёных гейтов по текущему диффу, при мусоре
или ослаблении в диффе, при `--no-verify`/`--force`, при сообщении не по формату. Отказ чинится
причиной. Есть `origin` - `git push` и `gh run list --limit 3`; красный CI - чини сразу.

## 6. Трекер

```
node scripts/tasks.mjs done <id> "<что сделано одной фразой>"
git add docs/90_WORKLOG.md docs/00_STATUS.md docs/tasks/tasks.json
git commit -m "chore(tracker): <id> done"
```

Файл дела - раздел `## Итог`.
