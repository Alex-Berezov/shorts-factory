# /gates - обязательные проверки

Аргументы: `$ARGUMENTS`

```
node .claude/hooks/gates.js $ARGUMENTS
```

Список гейтов - `.claude/hooks/rules.sf.json`, поле `gates`: `when: always` идёт всегда,
`glob:<шаблон>` - когда под шаблон подходит изменённый файл, `never` - только по `--only`.
`--list` показывает план и ничего не запускает; `--bail` останавливается на первом падении.

Отметку `lastGates` в `.claude/.qa-state` ставит **только полный прогон** без `--only`;
частичный полезен при работе, но замок коммита его не увидит.

## Как отвечать

Приведи фактический вывод: сводку по гейтам (id, команда, ok/ПАДАЕТ, время) и код возврата.
Пересказ словами вместо вывода не принимается ни при успехе, ни при падении.

Гейт упал - назови id, приведи его вывод и остановись. Чинить в этом же ходу можно, только
когда причина очевидна из вывода и правка укладывается в одну строку; иначе - `/fix` с текстом.
Упало из-за отсутствия инфраструктуры (`node_modules`, Docker) - так и напиши: это стоп-условие 4
для `/auto`, а не повод ослабить гейт.

Скрывать, отключать или обходить падающую проверку запрещено. Задача с красной проверкой
не закрыта.
