# Уроки: индекс

Строка на урок: правило и признак, по которому нарушение видно в диффе. **Ревьюеры и техлид
читают этот файл, а не журнал.** Признак совпал - открой полную запись:
`grep -n "^## L-0NN" .claude/qa-lessons.md` и `Read` с `offset`.

Новый урок пишется **в обе стороны**: полная запись в `qa-lessons.md`, строка сюда. Урок,
который целиком ловится регуляркой по добавленной строке, переносится в `standards`
файла `hooks/rules.sf.json` и убирается отсюда и оттуда.

| № | Правило | Признак в диффе или отчёте |
| --- | --- | --- |
| L-001 | Об успехе отчитывайся выводом самой проверки, а не словами | «всё зелёное», «проверки прошли» - и ни одной строки настоящего вывода в файле дела |
| L-002 | Посадку проверяй полным откатом дефекта, а не одной строкой | в файле дела «возврат дефекта ловит тест», а откат сделан переименованием или удалением одной строки |
| L-003 | Сверяешь аргументы вызова - ставь рядом `toHaveBeenCalledTimes` | в спеке `toHaveBeenCalledWith` без счётчика вызовов в том же `it(` |
| L-004 | Отсутствие входа - отдельный исход, а не успех | `catch { return null }` / `?? 0` / `\|\| []` вокруг чтения входа, и результат ведёт к записи или к «успешно» |
| L-005 | Проверка, которая не может провалиться, - не проверка | новый гейт/тест/правило добавлен без показанного красного прогона на заведомо плохом входе |
| L-006 | Стоимость внешнего вызова пишется до возврата результата и при ошибке тоже | вызов клиента YouTube/Gemini/TTS без `UsageLogger` в той же функции или лог только в ветке успеха |
| L-007 | Идемпотентность держит БД, а не «проверка перед вставкой» | `select` → `if (!exists) insert` без уникального индекса на той же паре колонок |
| L-008 | Правка хука или правила закрывается пробой на отказ И на пропуск | дифф в `.claude/hooks/**` без новой строки-пробы в `harness-selftest.js` |
| L-009 | Сравнение по времени берёт время оттуда же, откуда штамп | `new Date()` / `Date.now()` в одном выражении с колонкой, у которой `defaultNow()`; `$inferInsert` без `Omit` по такой колонке |
| L-010 | Границу, названную в нескольких документах, правь во всех разом | дифф меняет формулировку правила в одном документе, а `grep` по ключевой фразе даёт другие файлы, не тронутые тем же диффом |
| L-011 | Переезд типа между пакетами не ослабляет его ограничения | дифф удаляет `export type`/схему в одном пакете и добавляет одноимённую в другом, а набор обязательных полей или ширина union у них не совпадают |
| L-012 | Комментарий, объясняющий правку, проверяется прогоном, как и код | дифф добавляет комментарий с «иначе бы» или примером отказа, а в файле дела нет прогона, показывающего названное поведение; либо код условия снят, а абзац про него остался |
| L-013 | Не-2xx статус бывает штатным ответом роута, а не отказом | клиент ветвится по `response.ok` или списку статусов литералом, а схема роута объявляет не-2xx ключ со схемой успеха; либо состояние в union не получает ни один тест клиента |
| L-014 | Замок проверяется в той форме, в какой он ломается | дифф добавляет лимит, фильтр, условный вход или порядок в манифесте, а рядом нет кейса, где это ограничение единственное между входом и отказом; либо предел назван в единицах, в которых не считается |
| L-015 | Генерик, который «уточняет» вывод библиотеки, чаще его замещает | дифф добавляет параметр типа в вызов библиотеки рядом со схемой или дескриптором, а в файле дела один прогон - зелёный |
| L-016 | Фейк, отвечающий быстрее настоящей библиотеки, красит тест в зелёный по неверной причине | имя кейса про timeout/«gives up»/«не отвечает», а фейк резолвится мгновенно (`async () => value`, `vi.fn()` без реализации); либо «ручной прогон» проведён при доступной зависимости |
| L-017 | Проверка утечки ищет значения во всём, что уходит в браузер, а не имена в одном каталоге | сканер бандла ищет литерал имён, или сканирует один каталог, или без значений выходит «clean»; либо middleware авторизации пропускает ответ без `Cache-Control: private, no-store` |
| L-018 | Гейт, выбранный на файл, который его скрипт не читает, обещает проверку, которой нет | дифф расширяет `when` гейта, а скрипт из `cmd` новый путь не читает; или проба только на выбор гейта без красного прогона на испорченном файле |
| L-019 | Тест, читающий файл вне пакета, без входа в turbo отдаёт кэш вместо прогона | в диффе теста чтение/импорт через `../../../` или `ROOT`, а в `turbo.json` пакета нет `$TURBO_ROOT$/<путь>`; нет пробы cache miss |
| L-020 | Красный прогон засчитывается только той ветке, которая в нём упала | в файле дела FAIL меньше, чем веток отказа в новой пробе, или текст FAIL от соседней ветки; парсер пробы на неразобранном входе отдаёт `[]`/`continue` |
| L-021 | Переименование символа и расширение решения тянут за собой все текстовые ссылки на них | в диффе удалён идентификатор или изменён перечень/glob, а `rg` по старому имени в `docs/`, `.claude/` ещё находит его; ссылка на решение по номеру строки или по неоднозначным дате+id |
| L-022 | Переопределённый хук фреймворка тестируется по пути, которым его зовёт фреймворк | дифф переопределяет метод класса фреймворка, а тест зовёт его напрямую на свежем объекте; нет ссылки на место вызова в `node_modules`; уровень/ветки отличаются от базового метода без решения |
| L-023 | Предел склейки/TTL сверяется с реальным интервалом вызывающих; «сделано» - по `git diff` | в диффе TTL/окно склейки без сверки с интервалом healthcheck/автообновления; «сделано» по докблоку, а `git diff` этого места пуст |
| L-024 | Счётчик повторного сигнала учитывает двойную доставку одного нажатия и исход остановки | в диффе форс-ветка по второму SIGINT без окна по таймеру; код форс-выхода - литерал без учёта `failed`; нет юнита «две копии подряд» и SIGTERM -> SIGINT |
| L-025 | Страж разбирает адрес так же, как драйвер; правка текста скриптом без `$` в строке замены | в диффе страж на `new URL(...).hostname` без сверки с разбором драйвера; общий регэксп на разные отказные ветки; `.replace` со строкой-переменной; документ вырос вдвое |
| L-026 | Слушатель на общем соединении считается по числу подписчиков; асинхронный слушатель ждётся в тесте | в диффе `.on("error")` в цикле/фабрике по объектам на общем клиенте без кейса «одно событие на N»; отрицательный ассерт сразу после `emit` при `.then`/таймере в слушателе |
| L-027 | Починка ложного красного не сужает замок; «исчез» - по коду ENOENT, не по existsSync | в диффе замок с подстроки переходит на перечень форм без кейсов на прежний охват; `existsSync` в catch-ветке fs как доказательство отсутствия |
| L-028 | Ссылка теста снимается проверенным unlink до рекурсивного rm; разбор чужого формата - fail-closed | в диффе `symlinkSync`/junction в tmp и `rmSync(recursive)` того же каталога без `unlink` с проверкой кода; `catch {}` вокруг `unlink`; разборщик, возвращающий «чисто» на нераспознанном |
| L-029 | Общий помощник в диффе переводит все копии; комментарий ожидания называет механизм; ассерт до само-снимающего действия; время базы сравнивается в SQL | в диффе новый test-support при старых копиях той же формы рядом; пауза с комментарием без механизма; `expect` о lock/соединении после `close*()`; `new Date(<текст timestamptz>)` в границе окна |
| L-030 | Правка /fix - новый вход: метка вместо класса в фильтре ошибок, снимок env по именам, «прочее» - постоянный текст, монотонные часы, поля лога сверены с HEAD | в диффе `on("error")` с `return` по классу; `{ ...process.env }`; конкретная причина в последней ветке `catch`; `Date.now()` в окне; перенос строки лога без сверки ключей |
| L-031 | Предел вызова сверяется со всеми шагами (connect, fetch_types, каждый statement); окна - подзапрос на окно; кейс не разрывает пару «докблок - кейс» | в диффе `setTimeout(limit)` над несколькими запросами или открытием клиента; `least(...)` начала окон во внешнем `where`; новый `it`/`describe` сразу после чужого докблока |
| L-032 | Закреп того, без чего сервис не стартует, не заменяется выводом из манифеста; опровергнутое объяснение - rg по всем формулировкам; тест таймаута краснеет за конечное время | в диффе удалены явные `{ pkg }` пробы при выводе из `dependencies`; решение «X, а не Y» и живые тексты с Y; `spawnSync` в кейсе таймаута внутри vitest |
| L-033 | Маска `when` - только на видимый git путь; канал «значение из окружения» закрывается по всем полям одного поиска; предикат доступа без разрешающего умолчания | в диффе маска/`mustRun` на путь из `.gitignore`; отказ по `environment` без `build.args`/`secrets.*.environment`; `admits = () => true` |
| L-034 | Утверждение о поведении внешнего инструмента под сверкой - только по замеру живого инструмента, вывод в дело; сверять эффект, не настройку | в диффе докблок «turbo/инструмент делает X» у списка полей или ожидания без замера в файле дела; синтетический стаб и ожидание по одному допущению |
